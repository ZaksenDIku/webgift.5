# WebGift

WebGift er den første prototype af et firma, der laver digitale gavekort til familie, venner og de nærmeste.

Ideen er at gøre det nemt at give en personlig webbaseret gave, som kan deles online og føles mere personlig end et traditionelt gavekort. Prototypen viser den første version af oplevelsen og fungerer som et udgangspunkt for videre udvikling af produktet.

Denne version holder fokus på en enkel og personlig gaveoplevelse.

WebGift.2 bruges som den opdaterede arbejdsudgave til små forbedringer.
