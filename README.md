# WebGift.5

WebGift.5 er en webbaseret gaveoplevelse til personlige digitale gavekort. Projektet er bygget som en prototype, hvor billeder, tekst, citater og små sektioner kan samles til en gave, der kan deles online.

## Formål

Målet er at gøre det nemt at give en personlig gave, der føles mere nærværende end et traditionelt gavekort. WebGift kan bruges som en digital side til familie, venner eller andre nære relationer, hvor indholdet kan tilpasses modtageren.

## Indhold

- Personlig forside med hero-sektion
- Galleri og billedbaserede sektioner
- Citater, breve og fortællende indhold
- Komponenter til familie- og rejsefortællinger
- Responsivt layout til både mobil og desktop

## Teknologi

Projektet bruger React, TanStack Router, Vite og Tailwind CSS. UI-komponenterne bygger på Radix UI og lokale komponenter i `src/components`.

## Kom i gang

Installer dependencies:

```bash
npm install
```

Start udviklingsserveren:

```bash
npm run dev
```

Byg projektet:

```bash
npm run build
```

Kør lint:

```bash
npm run lint
```

## Projektstruktur

- `src/routes` indeholder appens routes
- `src/components` indeholder de genbrugelige UI- og sidekomponenter
- `src/lib` indeholder hjælpefunktioner, i18n og billedkonfiguration
- `public/images` er beregnet til offentlige billeder

## Status

WebGift.5 er en ny arbejdsudgave til små forbedringer og videre udvikling af den personlige gaveoplevelse.
